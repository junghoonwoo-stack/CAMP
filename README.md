# CAMP

**Company Agent Maturity Profile**

A ~10-minute assessment of how agent-native an organization is and what it should do next.

CAMP returns:
- Stage + Score /100
- biggest bottleneck
- next 90 days: Top 3 actions
- recommended AX / AI-native projects

## Benchmark: Give to Get

CAMP assessment is free. **Benchmark comparison requires contributing your anonymized assessment.**

Contributors may receive, when sample size is sufficient:
- Overall percentile
- Industry percentile
- anonymous Peer Group percentile
- five-dimension comparison

The public repository contains only the framework, schema, metadata, and synthetic examples. Raw benchmark data and real-company identity mapping stay private.

A company may optionally provide its identity privately for better deduplication, longitudinal tracking, and peer matching. Company names are never shown in the public benchmark.

Multiple people from one organization can use the same anonymous **Organization Group ID** and different **Respondent IDs**.

# CAMP

**Company Agent Maturity Profile**

약 10분 동안 조직이 얼마나 Agent-native한지, 다음에 무엇을 해야 하는지 진단합니다.

결과:
- CAMP Stage + Score /100
- 가장 큰 병목
- 향후 90일 Top 3 Action
- 추천 AX / AI-native 과제

## Benchmark: Give to Get

CAMP 진단 자체는 무료입니다. **Benchmark 비교를 받으려면 자신의 익명 진단 결과를 기여해야 합니다.**

표본이 충분하면 참여자에게 다음을 제공합니다.
- 전체 Percentile
- Industry Percentile
- 익명 Peer Group Percentile
- 5개 영역 비교

Public Repository에는 Framework, Schema, Metadata, 가상 Example만 둡니다. Raw Benchmark 데이터와 실제 회사명 Mapping은 비공개로 관리합니다.

원하면 회사명을 비공개로 제공해 중복 제거, 시계열 추적, Peer Matching 정확도를 높일 수 있습니다. 회사명은 Public Benchmark에 표시하지 않습니다.

한 회사에서 여러 명이 진단할 경우 같은 익명 **Organization Group ID**와 서로 다른 **Respondent ID**를 사용합니다.
