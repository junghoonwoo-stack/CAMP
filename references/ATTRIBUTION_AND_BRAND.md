# Attribution & Canonical Project

## English

CAMP is free to use, adapt, translate, teach, and use commercially under CC BY 4.0.

When redistributing CAMP or publishing an adapted version, use this attribution:

> **CAMP — Company Agent Maturity Profile**  
> https://github.com/junghoonwoo-stack/CAMP

If you publish an adapted version, indicate that it was modified.

The canonical CAMP project is the repository above and its official releases. Modified versions may say **“based on CAMP”** but should not imply that they are the official CAMP assessment, benchmark, or certification.

CAMP 자체를 재배포하거나 수정본을 외부에 공개할 때는 다음과 같이 출처를 표시해 주세요.

> https://github.com/junghoonwoo-stack/CAMP

수정본을 공개하는 경우 수정되었다는 점만 표시하면 됩니다.

공식 CAMP의 기준점은 위 저장소와 공식 Release입니다. 수정본은 **“based on CAMP”**라고 표현할 수 있지만 공식 CAMP 진단, Benchmark, 인증인 것처럼 표현하지 않습니다.
