# Attribution & Canonical Project

## English

CAMP is designed to be reused, translated, taught, and adapted widely.

When sharing or adapting substantial parts of CAMP, use this attribution:

> **CAMP — Company Agent Maturity Profile, created by Junghoon Woo**  
> https://github.com/junghoonwoo-stack/CAMP

If you modify CAMP, state that it is a modified version.

The canonical project is the `junghoonwoo-stack/CAMP` repository and its official releases. Modified versions may say **“based on CAMP”** but should not imply that they are the official CAMP assessment, an official benchmark, or a CAMP-certified program unless explicitly authorized.

If CAMP gains meaningful adoption, consider registering the project name and/or a distinctive logo as a trademark in relevant jurisdictions. Copyright protects the framework text; trademark protection is the stronger tool for protecting the identity of the official standard.

## 한국어

CAMP는 널리 사용하고, 번역하고, 교육하고, 수정할 수 있도록 공개합니다.

CAMP의 상당 부분을 공유하거나 수정해 사용할 때는 다음과 같이 원저자를 표시해 주세요.

> **CAMP — Company Agent Maturity Profile, created by Junghoon Woo**  
> https://github.com/junghoonwoo-stack/CAMP

수정한 경우 수정본임을 표시합니다.

공식 기준점은 `junghoonwoo-stack/CAMP` 저장소와 공식 Release입니다. 수정본은 **“based on CAMP”**라고 표현할 수 있지만, 별도 허가 없이 공식 CAMP 진단, 공식 Benchmark, CAMP 인증 프로그램인 것처럼 표시하지 않습니다.

CAMP가 의미 있게 확산되면 프로젝트 이름 또는 고유 Logo의 Trademark 등록을 검토하는 것이 좋습니다. Copyright가 Framework의 표현을 보호한다면, Trademark는 공식 CAMP의 정체성을 보호하는 데 더 적합합니다.
