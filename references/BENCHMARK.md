# CAMP Benchmark

CAMP Benchmark는 **명시적으로 동의한 조직의 익명화된 CAMP 결과만** 모아 상대적 위치를 보여주는 선택형 벤치마크입니다.

## 기본 수집 정보
- 제출일
- 국가
- 업종
- 진단 범위(회사/사업부/팀/AI-native 신설조직)
- 인원 구간
- Function
- CAMP Stage
- CAMP Score
- 5개 Dimension Score
- AI Operations 수준
- Sovereign AI 수준

기본적으로 회사명, 개인 이름, 이메일, 자유서술형 내부정보, 과제명/시스템명은 수집하지 않습니다.

GitHub Issue Form으로 제출하는 경우 회사명을 받지 않더라도 **제출자의 GitHub 계정은 공개될 수 있습니다.** 민감한 조직 정보는 Issue에 적지 않도록 안내합니다.

## 제출
Repository의 `CAMP Benchmark Submission` Issue Form을 사용합니다. 객관식/선택형 중심이며 Benchmark 공유에 동의한 경우에만 제출합니다.

## Ranking 원칙
- 전체 N < 10: 순위 제공 안 함 (`표본 부족`)
- 세부 그룹 N < 10: 해당 그룹 percentile 제공 안 함
- 기본 순위는 CAMP Score 기준 percentile
- 가능하면 Overall / Country / Industry / Size band를 분리
- 모든 비교에 표본 수 N과 기준일 표시

Benchmark는 경쟁 순위표가 아니라 조직이 자신의 상대적 위치와 투자 우선순위를 이해하는 보조자료입니다.
