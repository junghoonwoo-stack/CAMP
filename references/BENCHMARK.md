# CAMP Benchmark

## English

CAMP Benchmark is optional and includes only explicitly shared results.

### Identity
Use anonymous IDs, not company or personal names.
- **Organization Group ID:** same code for everyone in one organization
- **Scope ID:** `all` or an anonymous unit/team code
- **Respondent ID:** unique code for each respondent

### Multiple respondents
Several people from one organization may submit separate assessments.

CAMP reports:
- individual scores
- organization median/mean
- response spread, to show how consistently the organization is perceived

For cross-company ranking, one organization should count once. Organization-level aggregation is used so companies with more respondents do not dominate the benchmark.

### Minimum fields
Country, industry, scope, headcount band, function, CAMP Stage, CAMP Score, five dimension scores, AI Operations, and Sovereign AI.

Do not collect company names, personal names, email addresses, project names, system names, customer information, or free-form confidential content.

### Ranking
- Overall N < 10: no percentile
- Segment N < 10: no segment percentile
- Always show N and assessment date
- Prefer organization-level CAMP Score for external ranking

The benchmark is for learning and prioritization, not employee evaluation or vendor punishment.

## 한국어

CAMP Benchmark는 선택 사항이며, 명시적으로 공유에 동의한 결과만 사용합니다.

### 식별 방식
회사명이나 개인 이름 대신 익명 ID를 사용합니다.
- **Organization Group ID:** 같은 회사 응답자가 공통으로 사용하는 코드
- **Scope ID:** 회사 전체는 `all`, 또는 익명 사업부/팀 코드
- **Respondent ID:** 응답자별 고유 코드

### 여러 명이 응답하는 경우
한 회사에서 여러 명이 각각 진단할 수 있습니다.

CAMP는 다음을 함께 보여줍니다.
- 개인별 점수
- 조직 평균/중앙값
- 응답 분산도: 조직 내부에서 AX 상태를 얼마나 비슷하게 인식하는지

기업 간 순위에서는 한 회사가 한 번만 반영되도록 조직 단위 집계값을 사용합니다. 응답자가 많은 회사가 Benchmark를 왜곡하지 않게 하기 위함입니다.

### 최소 수집 정보
국가, 업종, 진단 범위, 인원 구간, Function, CAMP Stage, CAMP Score, 5개 영역 점수, AI Operations, Sovereign AI.

회사명, 개인 이름, 이메일, 과제명, 시스템명, 고객정보, 자유서술형 기밀정보는 수집하지 않습니다.

### Ranking
- 전체 N < 10: Percentile 미제공
- 세부 그룹 N < 10: 해당 그룹 Percentile 미제공
- N과 진단 기준일을 항상 표시
- 기업 간 비교는 조직 단위 CAMP Score를 우선 사용

Benchmark는 학습과 투자 우선순위 판단을 위한 것이며, 개인평가나 공급업체 제재용이 아닙니다.
