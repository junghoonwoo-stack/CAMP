# Contributing to CAMP

## English

Contributions are welcome.

By submitting a pull request or other contribution, you agree that your contribution may be distributed under the license that applies to the file or content you modify.

Please keep contributions:
- concise and evidence-based
- generalizable across organizations
- free of confidential company information
- compatible with the existing CAMP Stage and scoring logic, or clearly explain why the model should change

Major framework changes should include examples or evidence from more than one organization whenever possible.

Canonical project:
https://github.com/junghoonwoo-stack/CAMP

## 한국어

외부 기여를 환영합니다.

Pull Request 등으로 기여하는 경우 해당 파일이나 콘텐츠에 적용되는 라이선스에 따라 기여 내용이 배포될 수 있음에 동의하는 것으로 봅니다.

기여 내용은 다음을 권장합니다.
- 간결하고 Evidence 기반일 것
- 여러 조직에 일반화 가능할 것
- 회사 기밀정보를 포함하지 않을 것
- 기존 CAMP Stage/점수 체계와 호환되거나, 변경이 필요한 이유를 명확히 설명할 것

Framework의 큰 변경은 가능하면 여러 조직 또는 반복 관찰에 근거해야 합니다.

공식 프로젝트:
https://github.com/junghoonwoo-stack/CAMP
