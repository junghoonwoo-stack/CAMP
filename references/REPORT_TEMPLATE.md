# CAMP Report Template

## English

All reports are **anonymized**. Use `Your organization`, anonymous Organization Group ID, and anonymous Scope IDs instead of real company or team names.

### Executive result
- CAMP Stage + Confidence
- **CAMP Score /100**
- one-line diagnosis
- biggest bottleneck

### Five dimensions

| Dimension | Score | Interpretation |
|---|---:|---|
| AI Access | /20 | |
| AI Delegation | /20 | |
| Enterprise Connection | /20 | |
| Knowledge Compounding | /20 | |
| Role Transformation | /20 | |
| **Total** | **/100** | |

Always explain:
- strongest 1–2 dimensions and why
- weakest 1–2 dimensions and why
- major gaps or imbalance between dimensions
- what the score pattern implies for the next CAMP Stage

### Action
- next 90 days: Top 3 actions
- recommended projects
- Stop Doing
- AI Operations
- Sovereign AI

### Same-company analysis
If multiple assessments resolve to the same private Organization Group ID, also show:
- organization mean / median
- score distribution and range
- team / scope / function differences
- dimensions with the largest disagreement
- leadership vs frontline perception gap when role metadata supports it

Never show respondent identities.

### CAMP Bench
Benchmark comparison is available only to contributors.

When sample size is sufficient, show:

| Comparison | Position | N |
|---|---:|---:|
| Overall | Percentile | |
| Industry | Percentile | |
| Peer Group | Percentile | |

Also show:
- benchmark distribution with `Your organization` highlighted
- 5-dimension comparison against the selected cohorts
- relative strengths and weaknesses
- prior-period movement when longitudinal data exists

**Peer Group** = similar anonymous organizations by broad industry segment, size, country/region, scope, and function. If N < 10, broaden the cohort or show `Insufficient sample`.

Do not expose confidential participant company names or named-company scores. Named competitor comparisons may use only public or explicitly authorized named data.

## 한국어

모든 Report는 **익명화**합니다. 실제 회사명·팀명 대신 `Your organization`, 익명 Organization Group ID, 익명 Scope ID를 사용합니다.

### 핵심 결과
- CAMP Stage + Confidence
- **CAMP 총점 /100**
- 한 줄 진단
- 가장 큰 병목

### 5개 영역 분석

| Dimension | Score | 해석 |
|---|---:|---|
| AI Access | /20 | |
| AI Delegation | /20 | |
| Enterprise Connection | /20 | |
| Knowledge Compounding | /20 | |
| Role Transformation | /20 | |
| **Total** | **/100** | |

항상 다음을 해석합니다.
- 가장 강한 1~2개 영역과 이유
- 가장 약한 1~2개 영역과 이유
- 영역 간 큰 Gap / 불균형
- 이 점수 패턴이 다음 CAMP Stage에 무엇을 의미하는지

### Action
- 향후 90일 Top 3 Action
- 추천 과제
- Stop Doing
- AI Operations
- Sovereign AI

### 같은 회사의 여러 응답
Private Organization Group ID가 같은 진단이 여러 개면 다음도 보여줍니다.
- 조직 평균 / 중앙값
- 점수 분포와 범위
- 팀 / Scope / Function별 차이
- 의견 차이가 가장 큰 영역
- Role Metadata가 있으면 경영진과 현업의 인식 차이

응답자의 개인 identity는 표시하지 않습니다.

### CAMP Bench
Benchmark 비교는 데이터 기여자에게만 제공합니다.

표본이 충분하면:

| 비교 | 위치 | N |
|---|---:|---:|
| 전체 조직 대비 | Percentile | |
| 같은 업종 대비 | Percentile | |
| Peer Group 대비 | Percentile | |

추가로 보여줍니다.
- Benchmark 분포에서 `Your organization` 위치 Highlight
- 선택 Cohort 대비 5개 영역 비교
- Peer 대비 상대적 강점 / 약점
- 시계열 데이터가 있으면 과거 대비 변화

**Peer Group** = 넓은 Industry Segment, 규모, 국가/지역, Scope, Function이 유사한 익명 조직군입니다. N < 10이면 더 넓은 Cohort로 비교하거나 `표본 부족`으로 표시합니다.

비공개 참여기업의 회사명이나 Named Score는 공개하지 않습니다. 특정 경쟁사 이름이 붙은 비교는 공개정보이거나 명시적으로 허용된 데이터만 사용합니다.
