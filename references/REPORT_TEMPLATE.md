# CAMP Report Template

## English

Include:
- Stage + Confidence
- CAMP Score /100 + 5 dimensions
- One-line diagnosis
- Biggest bottleneck
- Top 3 actions for 90 days
- Recommended projects
- Stop Doing
- AI Operations
- Sovereign AI

For multiple respondents in one Organization Group ID, also show mean/median, score spread, and largest disagreements.

### Benchmark
After the report, ask for opt-in.

If shared and sample size is sufficient, show:

| Comparison | Position | N |
|---|---:|---:|
| Overall | Percentile | |
| Industry | Percentile | |
| Peer Group | Percentile | |

Also compare the 5 dimensions with the selected cohort.

**Peer Group** = similar anonymous organizations by broad industry segment, size, country/region, scope, and function. Do not show company names or named competitors. If N < 10, broaden the cohort or show `Insufficient sample`.

## 한국어

포함 항목:
- Stage + Confidence
- CAMP Score /100 + 5개 영역
- 한 줄 진단
- 가장 큰 병목
- 향후 90일 Top 3 Action
- 추천 과제
- Stop Doing
- AI Operations
- Sovereign AI

같은 Organization Group ID에서 여러 명이 응답하면 평균/중앙값, 점수 분산, 인식 차이가 큰 영역도 보여줍니다.

### Benchmark
Report 이후 공유 동의를 묻습니다.

공유했고 표본이 충분하면 다음을 보여줍니다.

| 비교 | 위치 | N |
|---|---:|---:|
| 전체 조직 대비 | Percentile | |
| 같은 업종 대비 | Percentile | |
| Peer Group 대비 | Percentile | |

5개 영역도 선택한 Cohort와 비교합니다.

**Peer Group** = 넓은 Industry Segment, 규모, 국가/지역, 범위, Function이 유사한 익명 조직군입니다. 회사명이나 특정 경쟁사 이름은 보여주지 않습니다. N < 10이면 더 넓은 Cohort로 비교하거나 `표본 부족`으로 표시합니다.
